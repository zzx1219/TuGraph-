## 三、聚合查询

### 1. 查询目的

设计聚合查询，显示导演们的名字出生年份，以及创作的电影数量。

### 2. 查询语句

```cypher
MATCH (p:person)-[produce]-(mnmovie) RETURN p.name AS 人名, p.born AS 出生年份, count(m) AS 制作电影数 ORDER BY 制作电影数 DESC
